# MY GYM COACH — первая версия

Это устанавливаемое PWA-приложение для iPhone и компьютера.

## Что уже работает
- Тренировочный цикл Upper/Lower с приоритетом верха.
- Запись каждого рабочего подхода: вес, повторения, заметка.
- История подходов, график рабочего веса, объём и счётчики.
- Локальные рекомендации по прогрессии на основе последних записей.
- Профиль и экспорт/импорт резервной копии JSON.
- Офлайн-кэш интерфейса после первого открытия.

## Важные ограничения первой версии
Данные хранятся в браузере на одном устройстве. Нет аккаунта, облачной синхронизации и автоматической связи с ChatGPT. Рекомендации пока основаны на простых правилах, а не на подключённой AI-модели.

## Как установить на iPhone
PWA нужно разместить на HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel):
1. Загрузить все файлы проекта на хостинг.
2. Открыть опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой» → «Добавить».

Для иконок `icon-192.png` и `icon-512.png` добавьте PNG-файлы соответствующих размеров. Если иконок пока нет, приложение всё равно можно открыть в Safari, но установка может показывать стандартную иконку.

## Следующий этап: настоящий AI-тренер
Для безопасного AI-подключения нужен серверный endpoint, который:
- принимает историю тренировок и профиль;
- передаёт контекст модели через OpenAI API;
- возвращает структурированный совет по следующей тренировке;
- хранит API-ключ только на сервере, не в браузере.

Нельзя помещать секретный OpenAI API key в `app.js` или другие клиентские файлы.
